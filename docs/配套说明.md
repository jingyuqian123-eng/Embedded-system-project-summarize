# 配套说明

## 1. 系统分工

```text
麦克风/KEY0
    │
    ▼
电脑上位机：录音 → 语音识别 → 大模型 → 生成回答和位图
    │ 115200 bps UART
    ▼
STM32F407：解析协议 → LCD 显示；KEY0 事件通过 UART 回传
```

当前 STM32 不直接访问公网 API，也不传输音频；它只负责实时 I/O 和显示。这样可以避免在资源有限的 MCU 上实现 HTTPS、JSON、语音识别和密钥管理。

## 2. 当前通信协议

启动后 STM32 发送：

```text
@DEV:<width>x<height>\r\n
```

电脑可发送：

```text
@REQ:DEV\r\n
@CMD:FORWARD;TEXT:已经开始向前走了\r\n
@PAGE\r\n
@ICON:SUN\r\n
@ROW:<x>,<y>,<hex bitmap row>\r\n
@IMG:<width>x<height>;LEN:<bytes>;X:<x>;Y:<y>\r\n<binary payload>
```

有效命令执行后 STM32 回复 `OK\r\n`，格式错误或尺寸超限回复 `ERR\r\n`。按键事件为：

```text
@BTN:DOWN\r\n
@BTN:UP\r\n
```

默认约束：波特率 `115200`，单行缓冲约 `200` 字节，黑白位图最多 `6144` 字节，最大宽度 `480` 像素。完整约束见 [`stm32_porting/protocol.md`](../stm32_porting/protocol.md)。

## 3. 下载与运行

1. 用 ST-Link/J-Link/CMSIS-DAP 将程序烧录到 STM32F407；USB-UART 不能烧录 Flash。
2. 将 USB-UART 的 TX 接 MCU PA10（USART1_RX），RX 接 PA9（USART1_TX），并共地。
3. 开发板上电后，电脑端应先收到 `@DEV`。
4. 如果收不到数据，检查 COM 口、交叉接线、共地、115200 波特率以及板上的 PA9/PA10 跳线帽。

## 4. 迁移到其他 STM32

先复制 [`stm32_porting/include/pc_demo_protocol.h`](../stm32_porting/include/pc_demo_protocol.h) 和 [`stm32_porting/src/pc_demo_protocol.c`](../stm32_porting/src/pc_demo_protocol.c)，然后完成：

1. 修改 UART 初始化、GPIO 和中断回调。
2. 将接收缓冲区设置为至少 200 字节；图片模式需要一段连续的二进制接收缓冲。
3. 将 `pc_demo_parse_cmd()` 的动作结果映射到电机、舵机或 LCD 绘制函数。
4. 按目标 LCD 分辨率回复 `@DEV`，并检查 `@IMG` 的宽、高、坐标和字节数。
5. 保留 `OK/ERR` 应答，电脑端据此判断位图是否发送成功。
