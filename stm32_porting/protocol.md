# 串口协议与移植约束

## 基本参数

| 项目 | 值 |
|---|---|
| UART | USART1（当前 F407 工程） |
| 引脚 | TX=PA9，RX=PA10 |
| 波特率 | 115200 |
| 格式 | 8 数据位、无校验、1 停止位 |
| 文本结束 | `\\r\\n` |
| 最大文本行 | 约 200 字节 |
| 位图格式 | 1 bit/pixel，行内高位先行 |
| 位图上限 | 480 像素宽，6144 字节 |

## 文本帧

电脑发送：

```text
@CMD:LEFT;TEXT:正在向左转\r\n
```

STM32 解析动作字段，`TEXT` 可用于串口回显或调试。成功回复 `OK\r\n`，失败回复 `ERR\r\n`。

## 位图帧

先发送 ASCII 头：

```text
@IMG:320x80;LEN:3200;X:0;Y:80\r\n
```

然后等待 MCU 切换到定长接收模式，再发送 `LEN` 个二进制字节。每行字节数为 `(width + 7) / 8`。不要把头和 payload 无间隔地一次性发送，否则简单的逐字节行接收器可能会抢先消费 payload。

## 迁移检查表

- 确保 UART 接收中断只负责收字节，不在中断中刷新 LCD。
- 完整收到 `\\r\\n` 后再解析文本帧。
- 位图头部先做宽、高、坐标和长度校验，再分配/接收 payload。
- 发送位图后回传 `OK/ERR`，上位机用 ACK 判断是否成功。
- 如果把动作映射到电机，必须增加急停、限速和通信超时自动停止。
